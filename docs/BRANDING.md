# 风车笔记 / pinwheel 名称检查

2026-10-27：0.10.4 发布包包含本次名称修复；鸿蒙源码版本为 0.2.4。旧 v0.10.3 安装包、源码快照和校验值保持不变，不能用旧安装包验证本次修改。

## 本次修正

- 修正宠物制作指南、示例包内的 README，移除废弃的旧品牌图标。
- 随附主题和模板不再把应用名替换为“星河札记”“海盐书房”等其他名字。用户自行定制文字的功能仍然保留，已有用户主题不被强制重写。
- 新加密文档导出使用 `.pinwheel`，宠物包使用 `.pinwheel-pet`，主题模板使用 `.pinwheel-theme.json`；更新桌面和鸿蒙的文件识别、导入、重命名、复制及系统关联配置。
- Windows 安装标记、构建变量、测试变量使用 PINWHEEL 名称；鸿蒙网页与原生桥接同步改为 PinwheelNative / pinwheel 回调。
- macOS 打包配置统一主程序和辅助程序的可执行文件名、应用名与 bundle ID。Electron Framework 和第三方许可证仍保留其原名。

## 有意保留的兼容标识

这些标识是既有数据的地址或格式，不是当前产品展示名称。不能全局替换，否则可能遗失配置或破坏文件读取。

- 桌面旧配置目录 `moye-notes` 和 `墨页`：仅用于迁移读取，已有 pinwheel 配置不覆盖。
- `.moye` 文档扩展名、`moye-pet` 清单与旧宠物包扩展名：继续导入。新版导出文件的扩展名不再采用旧名称。
- 加密文件头 `MOYEENC v1`：参与认证加密，桌面和鸿蒙继续采用已验证的兼容格式。不会修改已有文件的认证数据。
- 鸿蒙既有沙盒 `filesDir/moye` 和内部 `.moye` 配置/回收目录：保留原位置，避免升级后找不到笔记、设置和回收文件。
- Windows `.moye-install`：只用于识别、清理旧安装，新安装写入 `.pinwheel-install`。
- 历史审计报告、版本验证记录与第三方版权声明：保留真实历史，不将其中提及的其他软件改写为本项目名称。

内部测试环境变量已改为 `PINWHEEL_TEST_DATA`、`PINWHEEL_TEST_WORKSPACE`、`PINWHEEL_TEST_LOCALE`、`PINWHEEL_TEST_LEGACY_DATA`、`PINWHEEL_HEADLESS`、`PINWHEEL_PACKAGED_EXECUTABLE` 和 `PINWHEEL_BROWSER_CHANNEL`。运行自有测试脚本时应更新这些名称。

## 检查方式

`npm test` 包含新旧文档、宠物包、主题默认名称与示例内容检查；`python tests/macos_branding_test.py` 检查 macOS 主程序/辅助程序路径和元数据配对。桌面语言、迁移、加密导入导出、宠物素材工作室以及鸿蒙 Web 界面使用隔离目录测试。macOS 实机和鸿蒙原生 SDK 构建仍需对应平台验证。
