# 制作你的风车笔记主题

复制本目录的 `theme-template.json` 开始；`star-grid.json` 是深色网格示例，`ink-blue.json` 是兼容的旧版纯色主题。

想从更鲜明的成品风格开始，可复制 `neon-aurora.json`（霓虹宇宙）或 `pop-soda.json`（撞色波普）。它们包含配套的背景、字体、颜色和风格设置。

也可以在应用中先选一款喜欢的主题，然后在“设置 → 导出主题模板”保存一份可修改的 JSON。导出的内容仅包含主题设置，可以直接分享给别人。

## 使用方法

1. 用记事本等文本编辑器打开 JSON，修改名称、颜色或背景设置。
2. 保存为 UTF-8 的 `.json` 文件，注意不要保留 `.txt` 扩展名。
3. 在“设置 → 导入主题 JSON”选择文件，立即应用；重启后保留。
4. 调整后可再次导入；把 JSON 发给别人，对方也能导入使用。

JSON 不能写注释，每项之间保留英文逗号，最后一项后面没有逗号。保留 `themeApiVersion: 2`。文件大小上限 32KB。

## 颜色

`name` 是主题名，最多保留 40 个字符。`colorScheme` 为 `light` 或 `dark`，它会决定原生控件与代码高亮使用哪一组配色。

`tokens` 的十项颜色都必须存在，使用六位十六进制颜色，例如 `#89cce3`：

| 字段 | 作用 |
| --- | --- |
| bg | 正文底色 |
| sidebar | 左侧栏底色 |
| panel | 表格、设置等次级面板 |
| text | 主要文字 |
| muted | 次要文字 |
| border | 边框与分隔线 |
| accent | 强调色、链接、选中标记 |
| accent-bg | 选中项底色 |
| hover | 鼠标悬停底色 |
| code | 代码块底色 |

先调 `bg`、`text` 和 `accent`，再配其他颜色。让正文与底色有明显区分；背景纹理应比文字淡。

## 整体风格

版本 2 新增可选字段 `appearance`。它决定背景构图、侧栏、标题、品牌标识、边框和代码面板的视觉风格。导出内置主题时会一并保留，重新导入后仍呈现相同风格。旧模板未写此字段时使用 `plain`。

| appearance | 风格 |
| --- | --- |
| plain | 基础外观，自行配置颜色和背景 |
| light | 晨光：暖色棱镜、深紫侧栏、艺廊衬线标题 |
| dark | 夜色：酸绿信号、午夜网格、方角面板 |
| paper | 纸笺：勃艮第红书脊、奶油纸色、复古双线 |
| ocean | 潮汐蓝：深海流光、青色波纹、明亮水蓝标题 |
| sakura | 樱花手札：玫瑰与丁香紫、花瓣曲线、柔和圆角 |
| mint | 薄荷汽水：酸橙、钴蓝与淡紫撞色、硬边阴影 |
| sunset | 落日影院：橘红日轮、紫红地平线、胶片齿孔 |
| aurora | 极光夜航：霓虹光带、星点、青紫粉渐变标题 |
| vinyl | 黑胶爵士：香槟黑金、唱片纹路、衬线排版 |
| forest | 苔原来信：植物森系、叶片标本、浅绿纸张 |
| brutalism | 红黑宣言：极简海报、粗线条、红黑对照 |
| ink | 水墨山岚：远山构图、朱砂印章、东方留白 |
| blueprint | 蓝图工坊：深蓝底、双层网格、技术线框 |

建议从对应成品主题导出后修改，以保持明暗和对比度匹配。`background` 管理基础纹理层，`appearance` 另有自己的静态装饰层；希望完全去掉主题构图时，设置 `appearance: "plain"`。所有背景均不接收点击、不执行脚本、不加载网络资源，也没有持续闪动或循环动画。

## 字体

`typography.body` 控制正文，`typography.heading` 控制标题，`typography.interface` 控制侧栏、按钮和设置文字。三项分别选择：

- `sans`：Segoe UI / 微软雅黑，无衬线。
- `serif`：Georgia / 宋体，适合纸笺、手札。
- `mono`：Cascadia Code / Consolas / 微软雅黑，等宽风格。

字体按本机可用字体依次回退；代码块继续使用等宽字体。模板控制颜色、字体与背景，应用的编辑与响应式布局由程序保持一致。

## 背景

`background` 包含以下字段：

| 字段 | 可用值 |
| --- | --- |
| pattern | 下表中的一种图案 |
| color | 主背景色，格式如 `#89cce3` |
| secondary | 辅助背景色，同为六位颜色 |
| opacity | 图案透明度，数字 0 到 0.5；0 隐藏图案 |
| size | 点阵、网格、花瓣的间距，数字 16 到 256，单位像素 |

| 图案 | 效果 | 建议透明度 |
| --- | --- | --- |
| none | 无图案 | 0 |
| paper | 细密纸纹 | 0.05–0.12 |
| dots | 点阵 | 0.08–0.18 |
| grid | 网格 | 0.05–0.15 |
| waves | 两角柔和光晕 | 0.15–0.3 |
| aurora | 青紫或双色极光 | 0.15–0.35 |
| petals | 稀疏花瓣 | 0.08–0.18 |
| rings | 唱片状同心线 | 0.05–0.12 |

背景显示在编辑区底层，不接收点击，不随正文滚动。正文仍可选择和编辑；代码块、表格保留自己的面板底色。背景由程序生成，离线可用，不包含脚本或网络资源。

例如将背景改为浅网格：

```json
"background": {
  "pattern": "grid",
  "color": "#8aafbe",
  "secondary": "#b0c4d8",
  "opacity": 0.1,
  "size": 40
}
```

`size` 对光晕、极光、纸纹和同心线不生效，这些图案按窗口尺寸绘制。版本 1 主题仍可导入；重新导出时会生成版本 2 模板。

背景是编辑界面的装饰，笔记内容及导出文档继续使用各自的文档排版。

## 界面文字与图标

版本 2 的 `ui` 可省略；只写需要替换的项目，其他项目保持默认。`ui.labels` 的键是原来的中文文字，值是你想显示的文字。它只改变界面，不修改笔记正文、文件名、Markdown 语法和程序行为；系统原生文件选择框及动态错误信息继续使用程序文字。

```json
"ui": {
  "labels": {
    "风车笔记": "海盐书房",
    "pinwheel": "MY WRITING ROOM",
    "笔记": "手记",
    "大纲": "章节",
    "设置": "主题与外观",
    "新建文件": "新建手记",
    "新建文件夹": "新建分类",
    "创建文件": "创建手记",
    "导出": "带走文字"
  },
  "icons": {
    "brand": "✦",
    "settings": "✧",
    "folder": {
      "paths": ["M3 6h7l2 2h9v12H3z"],
      "strokeWidth": 1.5,
      "color": "#4f759a"
    }
  }
}
```

常用文字键：`风车笔记`、`pinwheel`、`本地`、`笔记`、`大纲`、`设置`、`文件树`、`列表`、`全部笔记`、`搜索结果`、`搜索笔记内容…`、`新建文件`、`新建文件夹`、`创建文件`、`创建文件夹`、`导入笔记`、`导出`、`历史版本`、`专注模式`、`Markdown`、`源码`、`加密文档`、`锁定文档`、`解锁文档`。按钮的悬浮提示、可访问名称与同名文字一起替换。文字最多 200 项，每项最多 200 字；短标签更适合小窗口。

| 图标名称 | 位置 |
| --- | --- |
| brand | 左上角品牌 |
| panel、book | 显示侧栏、专注模式 |
| file、folder、arrow | 文件、文件夹、展开箭头 |
| outline、list | 大纲、列表 |
| search、settings | 搜索、设置 |
| export、import、clock、lock | 导出、导入、历史、加密 |
| image、link、code、table | 图片、链接、代码、表格 |
| quote、bullets、tasks | 引用、列表、任务 |
| plus、check、close | 加号、成功、关闭 |

图标可以用字符/符号字符串，也可以用 `glyph` 对象，如 `{ "glyph": "✦", "color": "#4f759a" }`。文字图标最多 24 个字符，实际外观受本机字体影响。

0.7.0 增加 `copy`（创建副本）和 `rename`（重命名）图标名称。新增文字键包括 `重命名`、`确认重命名`、`创建副本`、`打开文件位置`、`复制文件路径`、`调整侧栏宽度`、`系统集成`、`开机自启`、`设置文件打开方式`、`全部风格` 及各风格类别名称。现有同类主题在设置中按类别合并展示，导出仍是单个主题。

矢量图标使用固定 `24 × 24` 坐标系，`paths` 为 1–8 个 SVG 路径的 `d` 字符串；`strokeWidth` 为 0.5–4，`color` 为可选六位十六进制颜色。未写颜色时跟随界面。这里只接受路径数据，不能粘贴整段 `<svg>`、HTML、脚本、图片 URL 或 CSS。
