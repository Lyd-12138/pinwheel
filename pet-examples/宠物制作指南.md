# 风车笔记宠物制作指南

你可以直接用应用里的部件编辑器和像素画板制作宠物，也可以使用任何绘画、动画软件制作 PNG、JPEG、WebP、GIF。

## 最容易的制作方式

1. 设置 → 桌面宠物，新增或编辑一个伙伴。
2. 调整体型、耳朵、眼睛、配色、花纹及配饰；或打开像素画板自由绘制。
3. 在“动作素材工作室”选择待机、摸摸、喂食、玩耍、睡觉、招手、拖动、落地，导入一张 GIF、逐帧图片或精灵图。
4. 逐帧图片按文件名的自然顺序播放，推荐命名 001.png、002.png。精灵图按从左到右、从上到下排列，可设置行列、起始帧、帧数和 FPS。
5. 导出 .pinwheel-pet 分享。接收者在设置里导入即可，素材会复制到自己的宠物库。

## 用自己的软件和文件夹制作

导出的包是 ZIP，解压后可以编辑 pet.json。图片放在同级或 assets/ 中。然后使用“导入宠物文件夹”选择该目录；应用自动计算校验值，无需手工维护 manifest.json。不要把修改过 pet.json 的文件夹直接重新压缩作为最终包，请先导入，再从应用导出。

pet.json 主要结构：

    {
      "name": "我的伙伴", "kind": "image", "color": "#a899ed",
      "actions": {
        "idle": { "kind": "frames", "files": ["assets/idle.gif"], "fps": 8, "loop": true, "duration": 1800 },
        "pet": { "kind": "frames", "files": ["assets/001.png", "assets/002.png"], "fps": 8, "duration": 1800 },
        "play": { "kind": "sheet", "files": ["assets/play.png"], "columns": 4, "rows": 2, "start": 0, "count": 8, "fps": 10, "duration": 2000 }
      },
      "behavior": { "click": "pet", "doubleClick": "play", "showSpeech": true, "messages": { "pet": ["你好呀！"] } }
    }

kind 可选 cat、fox、rabbit、robot、slime、image。没有配置动作素材时使用基础外形或主图，互动仍有应用提供的动作。

可增加自定义动作键，例如 wave、happy_dance（小写字母开头，最多 32 字符，后续使用小写字母、数字、下划线和连字符）。在动作中设置 label 作为菜单显示名称，并通过 behavior.click / doubleClick 绑定。自定义动作会出现在宠物右键菜单里。

appearance 可调 accent、outline 颜色；bodyWidth、bodyHeight、earSize、eyeSize、eyeDistance（0.65～1.3）；accessory 为 none/glasses/bow/scarf/crown，pattern 为 solid/stripes/spots，expression 为 round/happy/sleepy。图片宠物保持图片原有颜色。

动作 duration 单位毫秒，200～30000；fps 1～60。idle/sleep 循环直到下一次互动，其他动作按 duration 返回待机。关闭“待机动画”只停止呼吸、眨眼及待机素材轮播，手动互动仍可播放；系统减少动态效果设置会减少应用提供的位移动画。GIF 的内部时序由 GIF 文件决定。

## 限制与保存

每个动作最多 120 张图、最多 24 组动作；宠物包最多 300 张图片、80 MB，单图 10 MB、4096×4096。精灵图宽高必须整除行列数。素材只包含图片与配置，不执行脚本。导入后移动原始素材不会影响宠物；删除宠物会移除其应用内副本。导出包保留完整素材和配置。
